# Data Classification Using AI

## DecodeLabs AI Internship — Project 2

### Overview

This project demonstrates a basic supervised machine learning classification workflow using Python and Scikit-learn.

The Iris dataset is used to train a Decision Tree classification model that learns to classify iris flowers into different species.

### Project Objectives

* Load and understand a dataset
* Split the dataset into training and testing sets
* Train a classification model
* Make predictions using the trained model
* Evaluate model accuracy

### Dataset

The project uses the built-in **Iris dataset** provided by Scikit-learn.

The dataset contains:

* 150 samples
* 4 input features
* 3 flower classes:

  * Setosa
  * Versicolor
  * Virginica

### Machine Learning Algorithm

**Decision Tree Classifier**

The model is trained using 80% of the dataset and tested using the remaining 20%.

### Technologies Used

* Python
* Scikit-learn
* Decision Tree Classification

### How to Run

Open PowerShell in the project directory and run:

```bash
python classification.py
```
