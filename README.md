# Rule-Based AI Chatbot

## DecodeLabs Artificial Intelligence Internship — Project 1

### Project Overview

This project is a simple rule-based AI chatbot created using Python. It responds to predefined user inputs using conditional `if`, `elif`, and `else` statements.

The chatbot runs continuously until the user enters an exit command.

### Features

* Responds to greetings such as `hello`, `hi`, and `hey`
* Responds to "how are you"
* Provides a basic explanation of Artificial Intelligence
* Explains what the chatbot can do
* Identifies itself as a rule-based chatbot
* Responds to "thanks" and "thank you"
* Supports exit commands: `bye`, `exit`, and `quit`
* Handles unknown inputs with a default response

### Technologies Used

* Python
* `if`, `elif`, and `else` conditional statements
* `while` loop
* User input handling

### How to Run

1. Open PowerShell or the VS Code terminal.
2. Navigate to the project folder:

```powershell
cd C:\DecodeLabs_AI_Internship\DecodeLabs_AI_Project1
```

3. Run the chatbot:


